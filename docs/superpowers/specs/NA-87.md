# Trim self-generated artifact templates — Technical Spec

**Story:** NA-87 — Trim self-generated artifact templates
**Epic:** NA-76 — SDLC token and cost optimisation programme (workstream **B**, 5.2% of the programme's projected cut, Phase 1)
**Feature:** PRD referenced from the NA-76 Epic (`docs/features/2026-07-30-sdlc-token-cost-optimisation-programme.md`) — Jira is the product-context source for this spec
**Base:** `develop` @ `784a013` (post-NA-86 merge, PR #207)
**Date:** 2026-07-31

## Overview

Re-encode the five templates our own agents use to emit specs, plans, ADRs, QA review-round files
and memory rule entries, applying the NA-86 A1–A3 technique (unpadded tables + lean pseudocode on
procedural sections) to the templates **and** to the artifacts they produce. Nothing an artifact
*contains* may change — every section heading, field name and contract string survives; only the
encoding does.

**Non-goal restated for implementers:** if a diff removes a section, renames a field, or changes
what an artifact asserts, it is out of scope for NA-87 regardless of how many tokens it saves.

`instruction-inventory.sh --padding` reports **0** padded content rows across
`plugins/sdlc/**/*.md` outside fences — NA-86 A1 already unpadded them. The residual padding, and
the whole of B's 5.2%, lives in two other places:

| --- | --- | --- | --- | --- |
| `plugins/sdlc/skills/writing-specs/SKILL.md`, **inside** the template fence | 1 | 11 | 11 | A1's pass skipped fenced content |
| `docs/superpowers/specs/*.md` (produced artifacts) | 38 | 1,621 | 1,223 | agents copy the padded template |
| `docs/superpowers/plans/*.md` (produced artifacts) | 34 | 242 | 177 | same, via the tech-lead plan template |
| `.claude/memories/**/*.md` | 246 | 0 | 0 | no tables — leanness is prose-side only |

`docs/superpowers/` is already in `.prettierignore`, so nothing re-pads these artifacts: they are
padded because **the template taught the agent to pad them**. Spec docs average 7,757 est. tok and
plan docs 8,625 est. tok, and the pipeline re-reads a plan doc roughly nine times. Fixing the
template is therefore necessary but not sufficient — the templates must also carry an explicit
encoding contract that binds the artifact the agent writes.

### Contract shapes

`artifact-contract.sh` emits one `KEY=value` per line on stdout (same shape as `branch-inventory.sh`):

```text
TEMPLATE=plugins/sdlc/skills/writing-specs/SKILL.md
ARTIFACT=docs/superpowers/specs/NA-87.md
CONTRACT_TEMPLATE=14
CONTRACT_ARTIFACT=14
CONTRACT_MISSING=
CONTRACT_MATCH=true
```

```typescript
interface ArtifactContractReport {
  template: string; // path passed to --template
  artifact: string; // path passed to --artifact
  contractTemplate: number; // count of contract items extracted from the template
  contractArtifact: number; // count matched in the artifact
  contractMissing: string[]; // ordered contract items present in template, absent in artifact
  contractMatch: boolean; // contractMissing.length === 0
}

interface ExtractedContract {
  path: string;
  items: ContractItem[];
}

interface ContractItem {
  kind: "heading" | "field" | "fence" | "literal";
  value: string; // the exact string, verbatim
  line: number; // 1-based line number in the source file
}
```

**The content-contract extraction rule** (stated here because an unstated rule makes before/after
non-reproducible — same discipline as the padded-row rule in `tools/sdlc-analyser/README.md`):

A contract item is any of, in file order:

1. **heading** — every ATX heading (`#`…`######`), taken verbatim including its level.
2. **field** — every `<key>:` at the start of a trimmed line inside a fenced ` ```yaml ` block.
3. **fence** — every fence's info string (` ```bash `, ` ```typescript `, …), counted once per fence.
4. **literal** — every backtick-quoted inline span that is a path, a command, or an ALL-CAPS token
   (`STOP`, `blocked`, `N/A`).

Prose is **never** a contract item — that is exactly the surface B is allowed to compress.
Template placeholders (`[Feature Name]`, `<STORY-KEY>`, `NNNN`) match any artifact substitution at
the same position; comparison is positional and order-sensitive.

## Implementation Guide — `tools/` (platform-engineer, phase 1)

Stack rules that bind: POSIX-portable bash, must pass `bash tools/portability-lint.sh`, read-only,
never wired to mutate the repo. Follow the existing `branch-inventory.sh` output shape
(`KEY=value` per line) and its escalation rule — the tool is an aid, a written manual
reconciliation wins and goes in the PR body.

1. **`artifact-contract.sh`** — implements the extraction rule above. Two modes: `--extract <path>`
   (emit `ExtractedContract` as one item per line) and `--template <t> --artifact <a>` (emit
   `ArtifactContractReport`). Exit codes: `0` = `CONTRACT_MATCH=true`; `1` = mismatch; `2` = a path
   is unreadable, emit `CONTRACT_ARTIFACT=-1` plus a one-line `REASON=` and let the author supply a
   manual count. The non-zero exits are consumed by the **author**, not by CI — see D7 and D12.
2. **`instruction-inventory.sh --root <dir>`** — default stays `plugins/sdlc` so every existing
   invocation and every NA-86 measurement block reproduces byte-identically. For a root with no
   recognised top-level category directory, `category` is `artifact`. `--padding` and `--base`
   compose with `--root` unchanged.
3. **`tools/sdlc-analyser/README.md`** — document both, including the extraction rule verbatim and
   the "prose is never a contract item" carve-out.
4. **`.github/workflows/ci.yml`** — one added line invoking `artifact-encoding.test.sh`. No other
   CI change. `artifact-contract.sh` stays **manual**, consistent with the rest of the analyser set.

### B0 — the artifact-encoding contract

Create `plugins/sdlc/refs/artifact-encoding.md`, modelled on `refs/pseudocode-notation.md`: a
canonical, **never auto-loaded** reference. It states the rules an agent applies to the artifact it
is about to write:

| Rule | Statement |
| --- | --- |
| Unpadded tables | Emit `\| --- \|` delimiters and single-space cells; never align columns |
| No section drop | Every heading the template names is emitted, even when the answer is `N/A` |
| One-line N/A | A non-applicable section is one line (`**N/A** — <reason>`), never a paragraph |
| Verbatim contracts | Fenced code, field names, paths, commands and ALL-CAPS tokens copy exactly |
| Rationale as annotation | A "why" rides as a trailing clause or `#` comment on the rule it justifies, not as its own paragraph |
| Prose budget | Prose between two headings stays under 10 lines unless it is a decision the reader must make |

Each of the five templates gains **one** inline line (≤200 chars) naming the contract and pointing
at the ref — the NA-86 D5 pattern: a contract nobody loads is a contract that does not exist, and
200 chars/template is cheaper than a re-padded artifact.

**How AC-3 is actually satisfied — two tiers, decided in D12.** The post-change templates exist only
*inside* this PR, so no completed run can have produced all five artifact types against them before
it merges (a plan doc and a QA round file each need a full story execution). AC-3 therefore splits:

- **Tier 1 — pre-merge, blocking.** The implementer generates one **reference artifact per template**
  (a minimal but complete instance emitted from the post-change template), commits all five under
  `docs/superpowers/plans/NA-87-measurements/`, and runs `artifact-contract.sh` on each. All five
  must report `CONTRACT_MATCH=true`. This is the merge gate.
- **Tier 2 — post-merge, verification.** The first real story run after merge (NA-88, the natural
  Phase-1 successor) produces a genuine spec doc and plan doc from the post-change templates; the
  author re-runs `artifact-contract.sh` on those two and records the result. Not a gate on this PR.

**"Blocks the PR" throughout this spec means author-enforced, not CI-enforced.**
`artifact-contract.sh` is a manual instrument (D7) — no CI job invokes it, because a CI job would
have no produced artifact to diff. The implementer runs it, pastes the output in the PR body, and
does not request merge on a `CONTRACT_MATCH=false`. Reviewers check the pasted output.
`artifact-encoding.test.sh` is the **only** CI-side guard in this story; do not wire
`artifact-contract.sh` into CI (that would contradict D7), and do not assume CI already covers the
contract diff (it does not).

**A change that cuts tokens but raises QA rounds or blocked rate cost more than it saved** — revert
it, do not argue it.

AC-1 (dollar cost) is **not** a gate on this story: the 8-point cost distribution has an IQR of
$68.72, so a single run proves nothing. It is confirmed once at end of programme.

## Error Handling

| Scenario | Behaviour | Enforcement | Exit / status |
| --- | --- | --- | --- |
| `artifact-contract.sh`: `CONTRACT_MATCH=false` on a tier-1 reference artifact | Do not request merge; a dropped heading or field is a contract regression, not a formatting nit | Author-run, author-enforced; reviewer checks the pasted output | exit 1 |
| `artifact-contract.sh`: `CONTRACT_MATCH=false` on a tier-2 artifact after merge | Open a follow-up PR that restores the missing item **in the template** (D8); never relax the tool, never revert NA-87 wholesale | Author-run on the next story's run | exit 1 |
| `artifact-contract.sh`: template or artifact unreadable | Emit `CONTRACT_ARTIFACT=-1` and a one-line `REASON=`; author supplies a manual reconciliation in the PR body | Author-run | exit 2 |
| `artifact-contract.sh` count disagrees with a hand count | Manual reconciliation wins and must be written into the PR body (README escalation rule) | Author-run | n/a |
| `artifact-encoding.test.sh`: a template lacks the encoding pointer line | Fail with the offending path | **CI** | exit 1 |
| `artifact-encoding.test.sh`: an in-fence table row is padded | Fail with path + line number | **CI** | exit 1 |
| `artifact-encoding.test.sh`: `artifact-encoding.md` appears in an auto-loaded list | Fail — the ref must stay pointer-only, or it becomes a per-dispatch cost | **CI** | exit 1 |
| `instruction-inventory.sh --root <dir>` where dir does not exist | Fail with the resolved path; never fall back to `plugins/sdlc` silently | Author-run | exit 1 |
| `check-frontmatter.sh` fails after a schema-section edit | The edit changed a field name — revert it; the 5-field and 7-field schemas are frozen | **CI** | exit 1 |
| An agent emits a padded table into a new artifact after the change | Not a failure of this story's gates (artifacts are prettier-ignored); caught at review, and the encoding contract line is the fix | Reviewer | n/a |
| A produced artifact omits a template section | `artifact-contract.sh` reports it in `CONTRACT_MISSING`; the artifact is regenerated, the template is not loosened | Author-run | exit 1 |

**Validation rules (encoding-level):**

- A converted section must not change its own step count, step order, or step outcomes.
- No pseudocode block may use a ` ```bash ` fence (something might execute it) — plain or ` ```text `.
- Every frontmatter field name, artifact heading, and ALL-CAPS contract token survives byte-identical.
- Every compressed rationale leaves its operative claim attached to the rule it justifies.
