# Shrink SDLC plugin instruction surface — Technical Spec

**Story:** NA-86 — Shrink SDLC plugin instruction surface
**Epic:** NA-76 — SDLC token and cost optimisation programme (workstream **A**, 26.8% of the programme's projected cut)
**Feature:** PRD referenced from NA-76 comment (`docs/features/2026-07-30-sdlc-token-cost-optimisation-programme.md`, PR #201) — Jira is the product-context source for this spec
**Date:** 2026-07-30

## Overview

Re-encode and lazy-load the SDLC plugin's own instruction files (A1, A2/A3, A5–A9, A10) so an
8-point story's instruction load trends toward the programme's ≤230,000-token gate. Nothing a
`/sdlc:*` command or agent **does** may change — this is encoding, packaging and load-timing only.

**Non-goal restated for implementers:** if a diff changes the order, count, or outcome of any step,
it is out of scope for NA-86 regardless of how many tokens it saves.

## API Surface

**No HTTP API.** This story ships no endpoints, no routes, no request/response bodies. The
equivalent public contract is the **shell-script CLI surface** — those are the interfaces other
instruction files bind to, and they are versioned by the plugin release. They are specified here
with the same rigour, including a permission row per entry point (the Claude Code Bash allowlist is
this project's permission analogue).

### New script contracts

| Script                                     | Invocation form                                                                | Exit 0 means                    | Statically analysable |
| ------------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------- | --------------------- |
| `scripts/loop-budget.sh`                   | `bash <root>/scripts/loop-budget.sh init` \| `... check <head> <unresolved> [--grace]` | Budget not exceeded       | Yes                   |
| `scripts/resolve-ai-workflow-mode.sh`      | `bash <root>/scripts/resolve-ai-workflow-mode.sh <ISSUE-KEY>`                  | A mode line was emitted         | Yes                   |
| `scripts/assert-workspace-clean.sh`        | `bash <root>/scripts/assert-workspace-clean.sh snapshot <primary-root>` \| `... assert <primary-root> <state-file>` | Snapshot taken / unchanged | Yes |
| `tools/sdlc-analyser/instruction-inventory.sh` | `bash tools/sdlc-analyser/instruction-inventory.sh [--padding] [--base <git-ref>] [--json]` | Inventory emitted | Yes           |
| `tools/sdlc-analyser/branch-inventory.sh`  | `bash tools/sdlc-analyser/branch-inventory.sh <file> [--base <git-ref>]`        | Counts emitted                  | Yes                   |
| `tools/sdlc-analyser/cache-analysis.py`    | `python3 tools/sdlc-analyser/cache-analysis.py <label> <transcript.jsonl>...`   | Report emitted                  | Yes                   |

**Invocation rule (non-negotiable):** every call site must be a single `bash <path> <args>` form —
never wrapped in backticks, never built by string interpolation. `$(...)` capture is permitted
**only** in the established `eval "$(bash …)"` shape already used by
`scripts/read-review-config.sh`. Rationale: the Bash permission matcher statically parses the
command; an unparseable form falls through to an interactive ASK prompt regardless of allowlisting
(`refs/permission-prompt-audit.md`, root cause #1).

### Contract shapes

Contracts are stated as TypeScript interfaces for precision; the implementations are shell and emit
these as `KEY=value` lines (eval-able) or JSON where marked. No `any`, no optional-by-accident.

```typescript
// scripts/loop-budget.sh check — stdout, one KEY=value per line, eval-able
interface LoopBudgetResult {
  BUDGET_DECISION: 'CONTINUE' | 'STOP_IDLE' | 'STOP_PASSES';
  BUDGET_PASS_COUNT: number; // post-increment
  BUDGET_IDLE_SECS: number; // clamped to >= 0 on clock skew
  BUDGET_PROGRESS: 'true' | 'false'; // head oid or unresolved count changed since last pass
  BUDGET_REASON: string; // one line, human-readable; empty string when CONTINUE
}

// scripts/resolve-ai-workflow-mode.sh — stdout, one KEY=value line
interface AiWorkflowModeResult {
  MODE: 'Full Auto' | 'Auto' | 'Assisted' | ''; // '' only when neither field nor label is set
  MODE_SOURCE: 'field' | 'label' | 'default-unreadable' | 'none';
}

// scripts/assert-workspace-clean.sh snapshot — stdout, one KEY=value per line
interface WorkspaceSnapshotResult {
  PRIMARY_HEAD: string; // 40-char oid
  PRIMARY_STATE_FILE: string; // absolute path inside the session tmp dir
  PRIMARY_PRE_DIRTY: 'true' | 'false'; // true => caller emits the pre-existing-dirt WARNING

// scripts/assert-workspace-clean.sh assert — stdout, one KEY=value per line
interface WorkspaceAssertResult {
  WORKSPACE_INTEGRITY: 'OK' | 'VIOLATED';
  WORKSPACE_VIOLATION: 'none' | 'head-moved' | 'worktree-changed' | 'both';

// tools/sdlc-analyser/instruction-inventory.sh --json
interface InstructionInventoryRow {

  bytes: number;

interface InstructionInventoryReport {
  mode: 'inventory' | 'padding';

  rows: InstructionInventoryRow[];
  totalEstTokens: number;
  totalEstTokensAtBase: number; // 0 when no --base
  deltaEstTokens: number; // negative = saving
  // --padding only; all 0 in plain inventory mode.
  // headline figure = totalPaddedContentRows (delimiter rows reported separately, never merged)
  totalPaddedContentRows: number;
  totalPaddedDelimiterRows: number;
  totalPaddedContentRowsAtBase: number;
  deltaPaddedContentRows: number;
}

// tools/sdlc-analyser/branch-inventory.sh — stdout, one KEY=value per line
interface BranchInventoryResult {
  FILE: string;
  OUTCOMES_BASE: number; // distinct decision outcomes at --base
  OUTCOMES_HEAD: number; // distinct decision outcomes at working tree
  OUTCOMES_MATCH: 'true' | 'false';
```

## Implementation Guide — `plugins/sdlc/` (ai-enablement-engineer)

Stack rules that bind here: Markdown + Shell, kebab-case filenames, no informative/explanatory code
comments beyond what `refs/code-comments-policy.md` allows, every touched shell script must pass
`bash tools/portability-lint.sh`, and **never hand-bump** `plugins/sdlc/.claude-plugin/plugin.json`
(nx-release owns versioning post-merge).

### A1 — table unpad + prettier ignore (PR-1)

**What:** stop Prettier from padding markdown tables in `plugins/sdlc/**/*.md`, then unpad the
existing padded table rows once.

- Add `plugins/sdlc/**/*.md` to `.prettierignore`, with a comment naming NA-86 and ADR 0016 (the
  existing entries in that file all carry a "why" comment — match that convention).
- Capture the padded-row baseline **before** the unpad with
  `bash tools/sdlc-analyser/instruction-inventory.sh --padding --base <merge-base>`; the same call
  after the unpad supplies the "after" figure. Do not substitute a hand-run grep — the counting rule
  must be the tool's, and the tool's rule is written down.
- Perform the one-time unpad as a **whitespace-only** transform: collapse intra-cell padding to a
  single space either side of the content, keep the leading/trailing `|`, keep the delimiter row
  functional (`| --- |` form is acceptable; alignment colons must be preserved where present).
- **Table semantics must not change**: same row count, same column count, same cell content,
  including empty cells. A cell whose content contains a `|` inside an inline code span must remain
  escaped exactly as today (this is a known Prettier corruption signature — see ADR 0002).
- Verify by a rendered-content diff, not a byte diff: for each touched file, the parsed table
  content before and after must be identical.

**Verification of AC-8 ("check-plugin-docs-format.sh does not re-pad"):** add
`scripts/__tests__/prettier-ignore.test.sh` asserting all three of:

1. `pnpm exec prettier --file-info plugins/sdlc/commands/auto.md` reports `"ignored": true`.
2. The same holds for at least one file per top-level plugin dir (`commands/`, `agents/`, `refs/`,
   `skills/`).
3. `plugins/gtm/README.md` still reports `"ignored": false` — proving the ignore rule is scoped and
   `check-plugin-docs-format.sh` is not left vacuously green.

Assertion 3 is load-bearing: `check-plugin-docs-format.sh` cannot itself distinguish "everything
matched is clean" from "everything matched is ignored" (its own header documents this prettier-CLI
limitation), so the non-vacuity proof must live in the new test.

### A2/A3 — lean pseudocode (folded into PR-2 and PR-3)

Applies to the **procedural** sections of the files those PRs already touch. Conversion rules are
mandatory and come from the Epic:

| Rule                                                                                             | Binding |
| ------------------------------------------------------------------------------------------------ | ------- |
| Preserve **exactly**: fenced code, inline code, URLs, file paths, commands, exact contract strings | MUST    |
| Rationale survives as `#` comments positioned next to the rule it justifies                       | MUST    |
| Ship a one-time notation legend (`:=`, `->`, `⊆`, `ASSERT`/`ELSE`, first-match-wins)              | MUST    |
| Never use a ` ```bash ` fence for pseudocode — use a plain or ` ```text ` fence                    | MUST    |
| Do **not** convert declarative sections: Why, Role, Inputs, Modes                                  | MUST NOT |
| Do **not** convert judgment steps: PE Step 2 task derivation, Step 4 prompt-contract items 4 and 6, agent role definitions | MUST NOT |

**Notation legend placement (Decision D5):** the canonical legend is
`plugins/sdlc/refs/pseudocode-notation.md` (single source, never auto-loaded). Every converted file
additionally carries **one** header line naming the five symbols inline, so a cold reader never has
to open the ref. The per-file line is capped at 200 characters.

**Branch-inventory gate (AC-7):** for **every** A2/A3-converted file, run
`bash tools/sdlc-analyser/branch-inventory.sh <file> --base <merge-base>` and paste the
`OUTCOMES_BASE` / `OUTCOMES_HEAD` / `OUTCOMES_MATCH` block into the PR body. `OUTCOMES_MATCH=false`
blocks the PR. Pseudocode's failure mode is the silent loss of an `else`/failure branch — this is
the only gate that catches it. The same gate is re-run by any **sibling** PR whose post-PR-1 rebase
produces a table conflict (ordering constraint 4).

### A5 — `commands/loop.md` fast path (PR-2)

Split into three, along the boundaries already in the file:

| Destination                    | Content                                                                                                   | Target size |
| ------------------------------ | --------------------------------------------------------------------------------------------------------- | ----------- |
| `commands/loop.md` (stays)     | Frontmatter, argument parse, Step 0 review-agent/mode resolve, Step 1 PR resolve, Step 3 status probe, the decision table, WAIT/exit, Report, Final action | ≈ 4k tok |
| `refs/loop-modes.md` (new)     | The two full mode bodies — Copilot path steps 2–5 and the in-session path CI-1…CI-f — plus the per-mode WAIT detail | ≈ 10k tok |
| `scripts/loop-budget.sh` (new) | The budget init + read/increment/progress-reset/clamp bash from "Global loop budget"                       | ≈ 0 context |

**Load rule:** `commands/loop.md` reads `refs/loop-modes.md` **only** when the pass reaches a
mode-specific body — i.e. after the decision table has determined the pass needs to act (fix,
re-request review, or run an in-session review). A pass whose decision is WAIT or clean-exit must
complete without reading it. The decision table itself stays in the fast path — a pass that could
not decide without the ref would defeat the split.

**Budget script contract:** the two bash blocks become `init` and `check` subcommands. The
`BUDGET_SECS` / `REREVIEW_GRACE_SECS` / `BUDGET_PASSES` defaults (1200 / 600 / 30) stay
env-overridable with exactly today's names and values. The clock-skew clamp, the empty/non-numeric
re-initialisation, and the progress-reset rule move into the script unchanged in behaviour. Rule 2b
selects the grace bound by passing `--grace`.

### A6 — `commands/auto.md` split (PR-2)

- Move the whole **Epic orchestration** section (E0–E5b, ≈3,936 tok) to
  `refs/epic-orchestration.md`. `commands/auto.md` keeps a **pointer only**: Step 0 resolves
  `ITYPE`, and reads the ref **only** when `ITYPE=epic`. The single-story path must never load it.
- Collapse the **two duplicated AI-Workflow JQL ladders** (story-mode resolution and E0's
  `epicFallback`) into `scripts/resolve-ai-workflow-mode.sh <ISSUE-KEY>`.

**Ladder behaviour that must survive byte-for-byte in the script:**

1. Field `"AI Workflow" = "Full Auto"` → `Full Auto`.
2. Field `is not EMPTY` → read the real value via `acli … --fields 'AI Workflow' --json | jq -r
   '.fields["AI Workflow"].value // .fields["AI Workflow"].name // .fields["AI Workflow"] // empty'`;
   empty result → `Auto` (set-but-unreadable ⇒ safe gated default).
3. Labels, most conservative first: `AI-Workflow:assisted` → `Assisted`, then `AI-Workflow:auto` →

4. Otherwise `MODE=""`.
5. Any probe error yields no match, which lands on the human-merge path. `Full Auto` is the **only**

The script is the only implementation; both call sites consume `MODE` / `MODE_SOURCE`. `MODE_SOURCE`
is new observability, not a behaviour change — no caller may branch on it.

## Implementation Guide — `tools/` (platform-engineer)

Port the three analyser artifacts out of `/tmp` (where they are one reboot from gone) into
`tools/sdlc-analyser/`. This is a **port with a documented CLI**, not a redesign — the measurement
math must match the Epic's published baseline or the before/after numbers become incomparable.

| Source (today)          | Destination                                    | Contract                                                                    |
| ----------------------- | ---------------------------------------------- | --------------------------------------------------------------------------- |
| `/tmp/cache_an.py`      | `tools/sdlc-analyser/cache-analysis.py`        | Per-model request/token/cache/$ table from transcript `.jsonl`; keep the `cache_read_input_tokens / total input` hit-rate figure — it is the ≥94% guardrail |
| `/tmp/plugin_rows.json` (data) | produced by `instruction-inventory.sh` | Static per-file inventory; `estTokens = bytes / 3.7`; exclude vendored `find-skills` + `skill-creator` from totals |
| `scratchpad/cost8.py`   | folded into `cache-analysis.py` `--per-story`  | Per-story cost roll-up                                                       |

- `instruction-inventory.sh --base <ref>` computes the same inventory at a git ref and prints the
  delta — this is what every PR's AC-5 measurement block pastes.
- **`instruction-inventory.sh --padding`** counts padded markdown table rows across
  `plugins/sdlc/**/*.md` and is the **sole authority** for A1's before/after padded-row figures. It
  emits two counts and never merges them:
  - `paddedContentRows` — table content rows (a line that, trimmed, starts and ends with `|`)
    containing at least one run of **2 or more consecutive spaces** between a `|` delimiter and cell
    content. **This is the headline figure.**
  - `paddedDelimiterRows` — alignment/delimiter rows (cells made only of `-`, optional leading/
    trailing `:`) whose dashes are padded to column width.
    The rule must be written out in `tools/sdlc-analyser/README.md`, because two plausible rules on
    the same tree give materially different answers (639 vs 746) and an unstated rule makes the
    before/after non-reproducible. Fenced code blocks are excluded from both counts — a `|`-shaped
    line inside a fence is not a table row.
- `branch-inventory.sh <file> --base <ref>` counts distinct decision outcomes. Counting rule must be
  documented in `tools/sdlc-analyser/README.md` and is deterministic: one outcome per `if`/`elif`/
  `else`/`case` arm, per `ASSERT`/`ELSE` pair, per decision-table row, and per explicit
  failure/`STOP`/`blocked` path. When the tool's count and the author's manual count disagree, the
  **manual reconciliation wins and must be written into the PR body** — the tool is an aid, not the
  authority.
- Scripts must pass `bash tools/portability-lint.sh`. Python is Python 3, stdlib only.
- These tools **read** transcripts and the repo. They must never write to the repo or to
  `~/.claude/`.

**Transcript scope note:** `cache-analysis.py` reads `~/.claude/projects/**/*.jsonl`, which is
outside the repo. That is read-only, deliberate, and the only place the runtime numbers exist.

## Validation gates (per PR, required by AC-5)

Every one of the 4 PRs carries its own measurement block. A lumped measurement across PRs fails
AC-5. Minimum block:

```text
### Instruction-load measurement (NA-86 PR-N)
base-ref:            <merge-base sha>
static inventory:    <before> -> <after> est tok   (delta -N)
padded table rows:   <before> -> <after> content rows   (instruction-inventory.sh --padding; PR-1 only)
runtime instruction load, one real story run: <before> -> <after> tok
cache hit rate:      <before>% -> <after>%   (gate: >= 94%)
requests per story:  <before> -> <after>     (gate: must not increase)
QA rounds:           <before> -> <after>     (gate: must not increase)
loop passes per PR:  <before> -> <after>     (gate: must not increase)
branch inventory:    <file>: base N / head N / match true    (A2/A3 files only)
```

| Metric                                    | Source              | Guardrail            |
| ----------------------------------------- | ------------------- | -------------------- |
| Instruction load per 8-pt story           | transcript + inventory | trending to ≤230,000 tok (AC-2) |
| Padded table rows (PR-1)                  | `instruction-inventory.sh --padding` | must reach 0 content rows |
| `cache_read_input_tokens` / total input   | transcript usage    | must stay ≥ 94%      |
| Requests per story                        | transcript count    | must not increase    |
| Avg + peak resident                       | transcript usage    | must decrease        |
| QA rounds per story                       | QA verdict block    | must not increase    |
| `Status: blocked` rate                    | QA verdict          | must not increase    |
| Review findings per round                 | code-reviewer output | must not increase   |
| Loop passes per PR                        | `pass_count` in the budget file | must not increase |
| Branch outcomes, per A2/A3 file           | `branch-inventory.sh` | must match exactly (AC-7) |

## Error Handling

| Scenario                                                            | Behaviour                                                                                              | Exit / status |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------- |
| `prettier-ignore.test.sh`: an `plugins/sdlc/**/*.md` file is not ignored | Fail CI with the offending path                                                                     | exit 1        |
| `prettier-ignore.test.sh`: `plugins/gtm/**` also became ignored      | Fail CI — the ignore rule over-reached and `check-plugin-docs-format.sh` is now vacuous                 | exit 1        |
| `branch-inventory.sh` reports `OUTCOMES_MATCH=false`                 | Block the PR; a lost `else`/failure branch is a semantic regression, not a formatting nit                | exit 1        |
| `branch-inventory.sh` cannot parse a file                            | Emit `OUTCOMES_HEAD=-1` and a one-line reason; the author supplies a manual count in the PR body        | exit 2        |
| `instruction-inventory.sh --padding` counts disagree with a hand grep | The tool wins; a hand grep is not an authority (its rule is unstated). Re-read the README rule.         | n/a           |
| Sibling PR rebase onto PR-1 produces a table conflict                | Re-run `branch-inventory.sh` on each conflicted file; `OUTCOMES_MATCH=false` blocks that sibling PR      | exit 1        |
| `loop-budget.sh`: budget file missing on `check`                     | Re-initialise it and return `BUDGET_DECISION=CONTINUE` with `BUDGET_PASS_COUNT=1` (today's tolerant behaviour) | exit 0 |
| `loop-budget.sh`: empty / non-numeric fields                         | Re-initialise those fields — never let an empty field coerce to a huge elapsed and trip on pass 1        | exit 0        |
| `loop-budget.sh`: `progress_epoch` in the future (NTP step-back)     | Clamp elapsed to 0 and reset the epoch                                                                  | exit 0        |
| `resolve-ai-workflow-mode.sh`: acli/JQL error                        | `MODE=""`, `MODE_SOURCE=none` → caller takes the **human-merge** path                                   | exit 0        |
| `resolve-ai-workflow-mode.sh`: field set but value unreadable        | `MODE="Auto"`, `MODE_SOURCE=default-unreadable`                                                         | exit 0        |
| `assert-workspace-clean.sh snapshot`: primary already dirty          | `PRIMARY_PRE_DIRTY=true`; caller warns once and proceeds                                                | exit 0        |
| `assert-workspace-clean.sh assert`: HEAD moved or tree changed       | `WORKSPACE_INTEGRITY=VIOLATED` → PE **STOPs the phase**, QA returns **`blocked`**                        | exit 0 (decision is in stdout, not the exit code) |
| `assert-workspace-clean.sh`: state file missing on `assert`          | `WORKSPACE_INTEGRITY=VIOLATED`, `WORKSPACE_VIOLATION=both` — fail closed                                 | exit 0        |
| Lazy ref (`loop-modes.md` / `epic-orchestration.md`) unreadable      | STOP with the missing path — never continue on a half-loaded contract                                    | STOP          |
| `instruction-inventory.sh --base <ref>` where ref is unknown         | Fail with the ref name; do not silently report a delta against `HEAD`                                    | exit 1        |
| `cache-analysis.py`: transcript dir absent                           | Fail with the resolved path; do not emit a zeroed report that looks like a result                        | exit 1        |

**Validation rules (encoding-level):**

- A converted file must not change its own step count, step order, or step outcomes.
- No pseudocode block may use a ` ```bash ` fence (something might execute it).
- Every extracted ref must be reachable from its parent by an explicit path — no "see the split
  file" without the path.
- Every rationale extraction leaves a `# rationale: <path>` pointer at the extraction site.
