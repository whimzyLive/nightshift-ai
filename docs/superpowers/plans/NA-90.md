# Bound domain-agent reads with offset/limit — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Story:** NA-90 — Bound domain-agent reads with offset/limit
**Spec:** [docs/superpowers/specs/NA-90.md](../specs/NA-90.md)
**Epic:** NA-76 — SDLC token and cost optimisation programme (workstream **E**, estimated 4.9% of the projected cut, Phase 3, MED risk)
**Date:** 2026-07-31
**Branch:** `feat/NA-90` (off `develop` @ `71d9ea8`)
**Agents required:** `platform-engineer`, `ai-enablement-engineer`
**Complexity:** Medium — 2 implementation phases, 2 agents, 15 tasks

**Goal:** Ship the `## Bounded reads` clause that makes a domain agent locate content with `Grep`/`Glob` before loading it and window its first read of a large file — **with the under-threshold carve-out mechanically protected**, because applying Grep-first indiscriminately is a net **loss** on 68.7% of its own target set — plus the measurement instrument that can prove or disprove the claim, and the CI presence guard.

**Architecture:** Two sequential agent phases on one branch, **platform-engineer first**. Phase 1 ships `tools/sdlc-analyser/read-bounding.py`, its Gate-2 falsifiability fixtures and author-run test, the README rule statement, the pinned recursive-corpus baseline, and the single `.github/workflows/ci.yml` line. Phase 2 ships every `plugins/sdlc/**` surface — the clause, its two playbook pointers, the 6-assertion CI guard, and the evidence files. platform-engineer is first because Phase 2's evidence task consumes the instrument and the baseline Phase 1 produces.

**Tech Stack:** Markdown (prettier-ignored plugin tree, ADR 0016), Bash (POSIX-portable, gated by `tools/portability-lint.sh`), Python 3 **stdlib only, 3.9-compatible** (this machine runs 3.9.6 — no `match`, no PEP 604 runtime unions), GitHub Actions.

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim from the spec and the founder's spec-review-gate rulings unless marked as a gap fill.

- **The under-threshold carve-out is load-bearing, not cosmetic.** 468 of 681 addressable reads (**68.7%**) are files at or under 400 lines, where the window returns the whole file anyway and the `Grep` is pure overhead. Worked case: a 2,100 est tok read over ~150 lines becomes `Grep 100 + 2,100 whole = 2,200` → **−100, a loss**. Converting the top 50% saves **101.6%** of attainable; converting all 100% saves only **100.0%**. A contract that applies Grep-first indiscriminately **increases** tokens across two-thirds of its own target set. **No task may omit or weaken this carve-out, and assertion (f) fails if any future edit does.**
- **Decision 1 — requests may rise (founder ruling, spec review gate, 2026-07-31, recorded as decided).** _"More requests are okay as long as the total token count decreases significantly."_ This **relaxes the Epic's "requests per story must not increase" guardrail for workstream E specifically** — and for E only. Every other Epic guardrail (cache hit rate ≥ 94%, QA rounds, blocked rate, review findings, loop passes) applies to E unchanged.
- **Decision 2 — "significantly" is `>= 9,020 est tok/story`** net reduction in domain-agent read volume, derived from the top decile of addressable reads (51.6% of attainable saving). Falsifiable both ways. **Net fall > 0 but < 9,020 while requests rise → REVERT, not argue.** The one permitted alternative is narrowing the contract under AC-2 and **re-piloting** — never re-scoring the same pilot against a softer number.
- **The request-count delta is REPORTED in every measurement block, never suppressed and never a pass/fail input.** The founder accepted more requests; that is not licence to stop counting them.
- **Static instruction cost is declared as a POSITIVE number, with its ratio.** `+395 est tok × ~4 domain dispatches ≈ +1,580 est tok/story`, which is **~18% of the 9,020 gate threshold**. Paid on every dispatch whether or not agents obey. Budget: **≤ 500 est tok** static. Record **the ratio, not just the absolute**.
- **The pilot reports the carve-out hit rate, not only the aggregate delta.** An aggregate win can mask systematic losses on the majority of reads; a low carve-out hit rate with a passing aggregate is a finding, not a pass.
- **C/E boundary — the four-row table, keyed on *is there a prior read?*** C (NA-88) owns every rule conditioned on one; E owns the **first** read's extent. E extends by ADDING a sibling section — **never** by editing C's text.

- [ ] **Step 2: Write the implementation**

Reuse `duplicate-reads.py`'s conventions exactly — `STORY_KEY_RE` / `story_key()`, `classify_category()` with the same four first-match-wins rules and `CATEGORY_ORDER`, `resolve_paths()` fail-loud, skip-and-count on an unparseable line. Python 3.9-compatible: no `match`, no PEP 604 unions.

```python
#!/usr/bin/env python3
import json
import math
import os
import re
import sys
from collections import defaultdict

STORY_KEY_RE = re.compile(r"([A-Za-z]{2,10}-\d+)")

CATEGORY_ORDER = [
    "plugin-instruction",
    "self-generated-artifact",
    "project-config",
    "source-other",
]

ORIGIN_ORDER = ["orchestrator", "subagent"]

DEFAULT_THRESHOLD = 2000
DEFAULT_WINDOW_LINES = 400


def story_key(git_branch):
    if not git_branch:
        return None
    match = STORY_KEY_RE.search(git_branch)
    return match.group(1).upper() if match else None


def classify_category(path):
    if "plugins/sdlc/" in path or ("/plugins/" in path and "/sdlc/" in path):
        return "plugin-instruction"
    if "docs/superpowers/" in path or ".claude/memories" in path:
        return "self-generated-artifact"
    if ".claude/" in path or os.path.basename(path) in ("CLAUDE.md", "AGENTS.md"):
        return "project-config"
    return "source-other"


def origin_of(transcript_path):
    return "subagent" if "/subagents/" in transcript_path else "orchestrator"


def result_text(item):
    content = item.get("content")
    if isinstance(content, str):
        return content
    if isinstance(content, list):
        parts = []
        for part in content:
            if isinstance(part, dict) and isinstance(part.get("text"), str):
                parts.append(part["text"])
        return "".join(parts)
    return ""


def scan(path, reads, results, skipped_counter):
    origin = origin_of(path)
    with open(path, encoding="utf-8", errors="ignore") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            try:
                record = json.loads(line)
            except (json.JSONDecodeError, ValueError):
                skipped_counter[0] += 1
                continue
            content = (record.get("message") or {}).get("content")
            if not isinstance(content, list):
                continue
            story = story_key(record.get("gitBranch")) or "unlabeled"
            for item in content:
                if not isinstance(item, dict):
                    continue
                if item.get("type") == "tool_result" and item.get("tool_use_id"):
                    results[item["tool_use_id"]] = result_text(item)
                    continue
                if item.get("type") != "tool_use" or item.get("name") != "Read":
                    continue
                inp = item.get("input") or {}
                file_path = inp.get("file_path")
                if not file_path:
                    continue
                reads.append(
                    {
                        "id": item.get("id"),
                        "path": os.path.expanduser(file_path),
                        "origin": origin,
                        "story": story,
                        "windowed": inp.get("offset") is not None or inp.get("limit") is not None,
                    }
                )


def size_reads(reads, results):
    sized, unmatched = [], 0
    for r in reads:
        text = results.get(r["id"])
        if text is None:
            unmatched += 1
            continue
        entry = dict(r)
        entry["estTokens"] = int(math.floor(len(text) / 3.7))
        entry["lines"] = text.count("\n") + 1
        entry["category"] = classify_category(r["path"])
        sized.append(entry)
    return sized, unmatched


def percentile(values, pct):
    if not values:
        return 0
    ordered = sorted(values)
    idx = int(math.ceil(pct / 100.0 * len(ordered))) - 1
    return ordered[max(0, min(idx, len(ordered) - 1))]
```
