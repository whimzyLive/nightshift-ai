# Offload top-level work to subagents — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Story:** NA-92 — Offload top-level work to subagents
**Spec:** [docs/superpowers/specs/NA-92.md](../specs/NA-92.md)
**Epic:** NA-76 — SDLC token and cost optimisation programme (workstream **G**, Phase 3, MED risk, 1 PR)
**Date:** 2026-08-01
**Branch:** `feat/NA-92` (off `develop` @ `49489bf`)
**Agents required:** `ai-enablement-engineer`, `platform-engineer`
**Complexity:** High — 3 sequential phases, 2 agents, 17 tasks
**Delivery:** plan + implementation in ONE PR. No plan branch, no plan PR.

**Goal:** Move three units of work that the top-level orchestrator executes inline — the QA quality-gate run, the Step-7 AC/plan verification, and the Step-6.5 docs-sync gate — out of the orchestrator's transcript, so their reads, their command output **and their instruction bytes** land in a short-lived `general-purpose` subagent (G1, G2) or a deterministic script (G3), while every decision they feed stays at the top level.

**Architecture:** Three sequential agent phases on one branch. **Phase 1 (`ai-enablement-engineer`)** ships every `plugins/sdlc/**` surface: the two subagent-only refs, the docs-sync gate script, the rewritten playbook steps, and two CI-wired guards. **Phase 2 (`platform-engineer`)** ships `tools/sdlc-analyser/work-placement.py`, its falsifiability fixtures and test, the README section, and three `.github/workflows/ci.yml` lines. **Phase 3 (`ai-enablement-engineer`)** ships ADR 0019, the measurement/pilot-obligation evidence, and the memory write. Phase 1 is first because Phase 2's `units[].signature` strings quote the dispatch contracts Phase 1 defines, and because the CI lines Phase 2 adds name test files Phase 1 creates. Phase 3 is last because the ADR and the measurement block record the as-shipped byte totals from Phase 1 and the instrument from Phase 2.

**Tech Stack:** Markdown (prettier-ignored plugin tree, ADR 0016; `docs/superpowers` is prettier-ignored too), Bash (POSIX-portable, gated by `tools/portability-lint.sh`), Python 3 **stdlib only, 3.9-compatible** (this machine runs 3.9.6 — no `match`, no PEP 604 runtime unions), GitHub Actions.

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim from the spec unless marked as a measurement or an amendment.

- **The byte cap is the real gate.** `bytes(qa-engineer-playbook.md) + bytes(principal-engineer-playbook.md) <= 73704`. Today, measured in this worktree at `49489bf`: 33,826 + 44,628 = **78,454**. The required net is **−4,750 B**. **Never raise the constant** — if the moves cannot reach it, STOP and report to the review gate (NA-91 F-9 precedent).
- **Do NOT modify `plugins/sdlc/refs/domain-agent-handoff.md`.** Two sections are byte-pinned by hard-equality CI assertions owned by other stories: `## Context reuse` = **exactly 868 bytes** (NA-88, `bounded-reads.test.sh` assertion (e), hard equality) and `## Bounded reads` = **1,005 bytes, cap 1,200** (NA-90, assertion (c)). G needs neither. `work-offload-budget.test.sh` re-pins both so G's own guard fails if G touches them.
- **Round-tripping is the failure mode this story exists to avoid.** A step whose full output must come back has not been offloaded — it has been round-tripped, at the cost of one extra dispatch for the same resident bytes. Every unit carries an explicit **return cap** (G1 2,000 B / G2 4,000 B / G3 200 B) and the cap is what CI and the pilot assert.
- **Moving a step does not move its decision.** Three things provably cannot move, no exception: any decision that routes the run (pass/fail, clean/blocked, which of the five docs buckets); any dispatch of a domain agent (one-level nesting limit, ADR-0012); any attestation about the **primary checkout** — a subagent cannot attest to its own isolation breach.
- **Every CI assertion must be provably falsifiable.** Each carries a named perturbation that flips it to FAIL (see **Falsifiability register**). Tasks 1.6 and 2.3 execute those perturbations and restore clean. **Two gates on this epic have already been caught unable to fail** (NA-87's tier-1, NA-91's F-6) — that is why the register is a task, not a paragraph.
- **A grep-for-a-token assertion is only falsifiable if the token is unique.** Every absence token in this plan was verified with `grep -c` in this worktree and occurs **exactly once**, in the block being moved, with **zero** occurrences in the sibling playbook. Re-verify after any rewrite before trusting the assertion.
- **A byte-cap perturbation may not use a stock constant.** Compute the filler as `(cap − actual_total + 1)` bytes at ship time. NA-91's F-9 shipped a 300 B perturbation against 1,177 B of won headroom and would have passed while broken.
- **NA-88 D11 — a fixture or gate generated by the agent authoring the thing under test is self-confirming.** It is a **smoke test, never a gate**. Every artifact this story produces is labelled accordingly *in the file itself*, not only here.
- **NA-92's own run cannot measure G.** Two independent reasons: (1) G changes the orchestrator's own step contracts, so the shipping run executes on the PRE-change contract; (2) `plugins/**` edits do not reach running agents — they read `CLAUDE_PLUGIN_ROOT` (the cache), not the repo. Every runtime row is **NOT CAPTURED** with a named successor pilot. Never estimated, modelled, or back-filled.
- **Cache-read ratio ≥ 94% is the binding guardrail (AC-2, verbatim):** *"Revert or re-sequence G. Never trade the guardrail for instruction surface."*
- **AC-5's 4.2% stays UNCOUNTED** until the pilot passes every gate. This story claims **6.92% of top-level tool-result bytes / 6.14% of top-level exposure** relocated to a tier costing 1/3.01×, plus **≤ −4,750 B** of impl-path instruction surface. It claims no dollar figure (8-pt IQR is $68.72; one run cannot move it).
- **Do NOT add a plugin agent definition** for a gate-runner or AC-verifier. An agent definition's frontmatter description is injected into every session, which lands **positive** on the always-loaded surface. Both units dispatch `subagent_type: "general-purpose"`.
- **Do NOT use the `Agent` tool's `model` param.** It exists and is verified (`model: enum(["sonnet","opus","haiku","fable"])`), but model routing is workstream H; using it here would confound G's measurement.
- **Analyser tools are read-only** — never write to the repo, to `~/.claude/`, or to any artifact scanned. Every shipped shell script passes `bash tools/portability-lint.sh`.

```bash
# when it can FULLY resolve both sides; anything it cannot resolve is `dispatch-unresolvable`.
set -uo pipefail

key="${1:-}"; prefix="${2:-}"; base="${3:-}"
emit() { printf 'DOCS_GATE=%s\nREASON=%s\n' "$1" "$2"; exit 0; }
[ -n "$key" ] && [ -n "$prefix" ] && [ -n "$base" ] \
  || emit dispatch-unresolvable "usage: docs-sync-gate.sh <STORY-KEY> <BRANCH_PREFIX> <BASE-BRANCH>"

# 1. Manifest, resolved checkout-independently from the base branch.
manifest="$(git show "origin/$base:.claude/project/docs-manifest.md" 2>/dev/null)" \
  || emit skip-no-manifest "no .claude/project/docs-manifest.md at origin/$base — repo opted out of docs"
[ -n "$manifest" ] \
  || emit skip-no-manifest "empty .claude/project/docs-manifest.md at origin/$base"

# 2. Changed-file set, story-branch-vs-base.
git fetch origin --quiet 2>/dev/null
changed="$(git diff --name-only "origin/$base...$prefix/$key" 2>/dev/null)" \
  || emit dispatch-unresolvable "cannot resolve origin/$base...$prefix/$key — dispatching (fail safe)"
[ -n "$changed" ] \
  || emit dispatch-unresolvable "empty diff for $prefix/$key — cannot confirm a skip (fail safe)"

# 3. Activated row scopes. A scope this script cannot fully expand is UNRESOLVABLE, not ignored.
#    Row form: | type | enabled | target-path | source | contract |
scopes=""
enabled_ref=0
while IFS= read -r line; do
  case "$line" in \|*)
    t="$(printf '%s' "$line" | awk -F'|' '{gsub(/^ +| +$/,"",$2); print $2}')"
    en="$(printf '%s' "$line" | awk -F'|' '{gsub(/^ +| +$/,"",$3); print $3}')"
    src="$(printf '%s' "$line" | awk -F'|' '{gsub(/^ +| +$/,"",$5); print $5}')"
    con="$(printf '%s' "$line" | awk -F'|' '{gsub(/^ +| +$/,"",$6); print $6}')"
    case "$t" in type|---*|'') continue ;; esac
    [ "$en" = "true" ] || continue
    case "$t" in *-reference|llms-txt) enabled_ref=1 ;; esac
    for s in $src $con; do
      case "$s" in
        scan:) continue ;;
        *'{'*) emit dispatch-unresolvable "unexpandable scope '$s' on row '$t' — dispatching (fail safe)" ;;
      esac
      scopes="${scopes:+$scopes }$s"
    done
  ;; esac
done <<EOF
$manifest
EOF

# reference-roots apply when any reference-* / llms-txt row is enabled.
if [ "$enabled_ref" -eq 1 ]; then
  roots="$(printf '%s\n' "$manifest" | sed -n 's/^reference-roots:[[:space:]]*//p' | head -1 | tr ',' ' ')"
  [ -n "$roots" ] || emit dispatch-unresolvable "reference rows enabled but no reference-roots: line — dispatching (fail safe)"
  scopes="${scopes:+$scopes }$roots"
fi
[ -n "$scopes" ] || emit dispatch-unresolvable "no resolvable activated scopes — dispatching (fail safe)"

# 4. Intersect. A single hit is enough.
for f in $changed; do
  for s in $scopes; do
    s="${s%/}"
    case "$f" in
      "$s"|"$s"/*) emit dispatch "$f falls inside activated scope $s" ;;
      $s)          emit dispatch "$f matches activated glob $s" ;;
    esac
  done
done

emit skip-no-tracked-files "none of the $(printf '%s\n' "$changed" | wc -l | tr -d ' ') changed files fall in an activated scope"
```
