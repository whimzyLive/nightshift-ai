## Issues

- Important: pipeline defined a draft status (`proposed`) but never the proposed→accepted
  transition, leaving the accepted-only write-path guard permanently unarmed.
- Minor: a literal bad-slug string quoted in a warning (denylist trip hazard).
- Minor: unspecified combined-flag input (`--distill "<focus>"`).

## Preventions

- For any status/lifecycle field, spec the TRANSITION events, not just the states.
- Never quote a forbidden token literally in guidance text.
- Mode/argument tables must cover combined inputs or explicitly reject them.
