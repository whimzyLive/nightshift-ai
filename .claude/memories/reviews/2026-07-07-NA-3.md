- Critical: `init.md` Step 5 verified the PMM doc AFTER the finalize `mv` — the atomic "discard on
  failure" guarantee was broken, producing a false "discarded" claim.
- Important: `portability-lint.sh` hardcoded to `plugins/sdlc` so the new `plugins/gtm` went
  unscanned.
- Important: repo `.gitignore` missing `.claude/.gtm-plugin-root` while the hook writes it
  pre-init.
- Important: finalize `mv` order made `marketing-context.md` land first, so a half-finalize looked
  like an existing foundation to the re-init guard.
- Minor x4: plan verify-check assumed string-array deps (should be object shape); `sed` dot-mangling
  on repo-name extraction; grep-based `package.json` reads (first-match, not top-level); undocumented
  drift-check omission.

## Preventions

- Any atomic-write step must verify ALL preconditions before the first `mv`.
- The file a re-init/existence guard keys on must be written LAST in a multi-file finalize.
- Shared repo tooling (lint) must enumerate `plugins/*/`, never hardcode one plugin.
- When a hook writes a file outside init, the repo shipping the hook needs the `.gitignore` entry
  itself.
